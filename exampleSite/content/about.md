Retro Fusion is a Hugo theme built around a simple idea: the early web was
fast, legible, and a bit strange, and most of that is worth keeping.

## What it is

A single stylesheet, a single small script, no build step, and no third-party
requests. Pages are plain HTML with semantic markup underneath the beveled
borders. It works with JavaScript turned off.

It ships two homepage layouts — a blog and a business landing page — switched
by one config value. Everything else is optional.

## What it is not

It is not a framework. There are no shortcodes to learn, no component library,
no plugin system. If you need a feature it does not have, the theme's own
templates are short and meant to be copied into your site and edited.

Some things are missing on purpose. See [Design Notes](/posts/design-notes/).

## How it was made

Parts of this theme were written with the help of AI, then reviewed, tested and
corrected by hand. Every page you are reading was built from the same templates
you have. Treat it as you would any other code you did not write yourself:
read it, test it against your own content, and use it at your own will.
