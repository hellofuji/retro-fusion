Four things, done properly. We don't do everything, and we'll tell you if your
project isn't a fit.

## Static Site Engineering

We build sites with [Hugo](https://gohugo.io/), hand-written CSS, and semantic
HTML5. No runtime dependencies, no build toolchain to maintain, no security
patches to apply on a Sunday.

**You get:** a Git repository, a documented build command, and a site that
deploys anywhere that serves files.

**Typical timeline:** two to six weeks.

## Retro Web Design

A visual language drawn from the Web 1.0 era — beveled borders, tiled
backgrounds, high-contrast palettes, honest typography — executed with modern
layout and real accessibility.

This isn't a gimmick. High-contrast, uncluttered, memorable design is *good*
design, and it's a genuine differentiator in a web where every site looks like
the same three SaaS templates.

**Typical timeline:** bundled with engineering.

## Performance Audits

We measure what your site actually ships, find the expensive decisions, and
hand back a prioritised list with fixes — not a Lighthouse screenshot and a
shrug.

We'll usually find:

- Images that are 5–10× larger than their display size
- Third-party scripts costing more than your entire first-party bundle
- Font stacks loading nine weights where one variable font would do
- A client-side framework rendering content that never changes

**Typical timeline:** one week.

## Care & Feeding

Monthly content updates, dependency and link-rot checks, uptime monitoring, and
a human who answers your email within a day.

**Billed monthly, cancel any time.** No lock-in, and you keep the repo
regardless.
